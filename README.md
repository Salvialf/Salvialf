# Salvialf

Self-taught developer, core developer at [Jeedom](https://www.jeedom.com), the French open source home automation software. I started in its ecosystem in 2019 with community widgets, and have been working on the core itself since 2020.

## At Jeedom

- **[Core](https://github.com/jeedom/core)**: 800+ commits, 120+ merged pull requests.
- **Plugins**: 1,800+ commits across 85+ plugins.
  - Author of several plugins, including [OCPP](https://github.com/jeedom/plugin-ocpp), [Enedis](https://github.com/jeedom/plugin-enedis), [jeeMeter](https://github.com/jeedom/plugin-jeeMeter), [Teleinfo PME-PMI](https://github.com/jeedom/plugin-teleinfoPMEPMI), [TP-Link SMS](https://github.com/jeedom/plugin-tplinksms) and [vlx2mqtt](https://github.com/jeedom/plugin-vlx2mqtt).
  - Major reworks of others, such as [Jeeasy](https://github.com/jeedom/plugin-jeeasy) (setup wizard), [WES Control](https://github.com/jeedom/plugin-wescontrol) and [Z-Wave JS](https://github.com/jeedom/plugin-zwavejs).
  - Several private professional plugins as well.
- **Docs, tooling and infrastructure**: 600+ commits on the [documentation](https://github.com/jeedom/documentations), the [jeetranslate](https://github.com/jeedom/jeetranslate) translation automation, shared [CI workflows](https://github.com/jeedom/workflows) and internal infrastructure (box image builds, Market, cloud services).

## Personal projects

- **[pve-scripts](https://github.com/Salvialf/pve-scripts)**: one-command creation of ready-to-use LXC containers on Proxmox VE, in the spirit of tteck's Helper-Scripts.
- **[Pimp my Jeedom](https://market.jeedom.com/index.php?v=d&p=market_display&id=4005)**: my first Jeedom plugin, available on the Jeedom Market ([documentation](https://salvialf.github.io/Salvialf-Documentation/pimpJeedom/fr_FR/), in French).
- **[Jeedom widgets](https://github.com/Salvialf?tab=repositories&q=JEEDOM-Widget)**: 18 dashboard widgets (icons, sliders, gauges, weather, Linky...), with their [documentation](https://salvialf.github.io/Salvialf-Documentation/index/fr_FR/) (in French).
- A few private side projects, from a Peggle-like game in Godot to Node.js web apps.
